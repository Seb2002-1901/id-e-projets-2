## Séquence d'exécution (l'ordre réel des opérations)

```
  A. PRODUIRE LE LIVRABLE
     ├─ 03 → monter le template Notion (importer les 365 défis)  ── ~2 j
     └─ export PDF premium + 6 bonus
  B. PRODUIRE LES VISUELS
     └─ 01 + 02 → 4 visuels P0/P1 dans Canva                     ── ~1 j
  C. MONTER LE TUNNEL
     └─ 04 → pages TinyPages + paiement + emails + test          ── ~1-2 j
  D. VÉRIFIER
     └─ 05 → checklist complète, achat test réel                 ── ~0,5 j
  E. LANCER & TESTER LE MARCHÉ
     ├─ 07 → batch 7 vidéos, bios, lien en bio
     └─ 06 → go-live + 14 jours de test + grille de décision
```

**Chemin critique estimé : ~5-6 jours de travail** pour une personne seule avant le go-live, puis 14 jours de test marché.
