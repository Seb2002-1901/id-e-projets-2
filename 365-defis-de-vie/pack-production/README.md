## 🚀 Comment utiliser le pack
1. **Design (Canva)** : importe `Assets/tokens/colors.json` comme référence de couleurs, utilise les SVG de `Assets/svg/` comme éléments, et les PNG de `Exports/` comme base directe. Suis `Canva/dossier-canva.md`.
2. **Notion** : importe les CSV de `Notion/` (voir `../execution-finale/csv/` pour le guide de formules).
3. **TinyPages** : colle les pages de `TinyPages/` (ordre : `../production/04-ordre-creation-tinypages.md`).
4. **Emails** : branche les séquences de `Emails/07-emails.md`.
5. **PDF** : suis `PDF/README.md`.
6. **Génération d'images** (optionnel) : les prompts de `Canva/prompts-generation-images.md`.

> Les fichiers de `TinyPages/`, `Emails/`, `Notion/`, `Canva/` sont des **copies** des sources canoniques (`lancement-commercial/`, `execution-finale/`, `apercu/`) rassemblées ici pour faire du pack un livrable autonome. En cas de doute, la source canonique fait foi.
