# LISEZ-MOI — Mode d'emploi du dossier (vendeur)

Ce dossier contient tout ce qu'il faut pour mettre en vente « Lucide — 30 jours pour reprendre la main sur l'alcool » ce soir. Ce fichier t'explique où est quoi, dans quel ordre agir, et ce qui n'est pas négociable.

---

## L'arborescence, commentée

```
lucide-produit-digital/
├── LISEZ-MOI.md          ← ce fichier
├── PRODUIT/
│   ├── pdf/              ← ce que le client achète (les fichiers livrés tels quels)
│   └── src/              ← les sources Markdown modifiables (à convertir en PDF après toute retouche)
├── VENTE/                ← tout le kit Gumroad : page de vente, visuel de couverture, e-mails, checklist
└── LEGAL/                ← à lire AVANT de vendre : avertissement santé, remboursement, mentions
```

- **PRODUIT/pdf** : le livrable client. On ne touche jamais directement aux PDF — on modifie les sources.
- **PRODUIT/src** : la vérité du contenu. Toute correction se fait ici, puis on régénère les PDF.
- **VENTE** : tout ce qui sert à vendre, rien de plus.
- **LEGAL** : court, mais obligatoire. L'avertissement santé qui s'y trouve doit figurer dans le produit ET sur la page de vente.

## Le chemin critique ce soir

1. Lire `LEGAL/avertissement-et-remboursement.md` en entier et compléter les mentions vendeur (section 4).
2. Suivre `VENTE/MISE-EN-VENTE-CE-SOIR.md` étape par étape.
3. C'est en ligne.

Rien d'autre n'est bloquant. Tout le reste peut s'améliorer demain.

## Les 5 règles non négociables du produit

1. **Jamais promettre de résultats.** Pas de délai garanti, pas de transformation assurée, pas de chiffre d'efficacité inventé. La seule promesse autorisée est celle du produit : « On ne te promet pas que ce sera facile. On te promet que tu ne seras plus jamais surpris. »
2. **Jamais de faux témoignages.** Le produit se lance ce soir : il n'existe aucun témoignage, donc on n'en affiche aucun. L'honnêteté est l'argument de vente, pas son obstacle.
3. **L'avertissement santé reste visible.** Dans le produit, sur la page de vente, partout. On ne le raccourcit pas pour faire joli.
4. **Le remboursement est honoré sans discuter.** 30 jours, intégral, aucune justification demandée. Une demande de remboursement se traite sous 48 h maximum — le jour même si tu peux.
5. **On ne vend jamais dans les groupes d'entraide.** Forums, groupes de soutien, communautés de personnes en difficulté avec l'alcool : ce sont des espaces de soin, pas des canaux d'acquisition. Aucune exception.

## Note sur la marque

« Lucide » est un nom de travail. Avant d'investir dans la marque (logo payant, nom de domaine premium, communication à grande échelle), vérifier la disponibilité du nom auprès de l'INPI (base des marques) pour la classe de produits concernée. Ce soir, on peut vendre sous ce nom ; on ne construit pas dessus tant que ce n'est pas vérifié.
