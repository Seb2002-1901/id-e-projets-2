# Guide Go‑Live — Mettre Cap365 en vente

> Objectif : la checklist finale avant d'ouvrir les ventes, puis les premières 48 h. Coche chaque case. ⏱️ ~1 h de mise en place.

---

## A. Juridique (obligatoire avant la 1ʳᵉ vente)
- [ ] Publier les **CGV** → `../Documents/legal/01-cgv.md`
- [ ] Publier la **politique de remboursement** (garantie **30 jours**) → `../Documents/legal/02-politique-remboursement.md`
- [ ] Publier la **politique de confidentialité** → `../Documents/legal/03-politique-confidentialite.md`
- [ ] Publier les **mentions légales** → `../Documents/legal/04-mentions-legales.md`
- [ ] Afficher la **clause de non‑garantie de résultats** → `../Documents/legal/05-clause-non-garantie-resultats.md`
- [ ] Afficher les **avertissements** → `../Documents/legal/06-avertissements.md`
> Complète les champs entre crochets (raison sociale, adresse, e‑mail de contact) avec **tes** informations réelles.

## B. Paiement
- [ ] Créer les **3 produits** aux bons prix : Le Sentier **19 €**, L'Ascension **39 €**, Le Sommet **89 €** (Stripe, TinyPages, Gumroad… au choix).
- [ ] Vérifier que le **lien de paiement** de chaque page mène au bon produit.
- [ ] Configurer l'**e‑mail de livraison** (accès + duplication du template Notion) → voir `../TinyPages/05-page-merci.md`.

## C. Contenu en ligne
- [ ] Pages publiées : accueil, landing, produit, paiement, merci, FAQ (`../TinyPages/`).
- [ ] Visuels en place (hero, offres, écrans) depuis `../PNG/` et `../SVG/`.
- [ ] Séquence e‑mail branchée (`../Emails/sequences-email.md`).
- [ ] Mentions **« exemple fictif »** visibles sous chaque témoignage.

## D. Notion prêt à livrer au client
- [ ] Les 3 commandes du Builder ont tourné (voir `GUIDE-MAC.md`).
- [ ] Les **vues** manuelles sont créées (voir `../Builder/POST-INSTALL-V3-REPORT.md`).
- [ ] Le template est **dupliquable** (bouton « Dupliquer » testé depuis un autre compte).

## E. Achat‑test (le plus important)
- [ ] Faire un **vrai achat** de bout en bout (idéalement en navigation privée).
- [ ] Vérifier : paiement OK → e‑mail reçu → accès/duplication du template OK.
- [ ] Tester une **demande de remboursement** fictive pour valider le process.

---

## Ouverture des ventes
- [ ] Publier le lien principal (landing) sur tes canaux.
- [ ] Lancer la séquence e‑mail.
- [ ] Surveiller : 1ʳᵉ vente, 1ᵉʳ e‑mail de support, 1ʳᵉ question FAQ.

## Premières 48 h
- [ ] Répondre vite aux questions (gabarits dans `../TinyPages/06-faq-garanties-objections.md`).
- [ ] Noter les objections récurrentes → ajuster la landing.
- [ ] Demander un **avis réel** à chaque premier client satisfait (pour remplacer les témoignages fictifs).

> Bilan, risques et verdict de lancement : **[`../Rapports/00-RAPPORT-FINAL-ULTIME.md`](../Rapports/00-RAPPORT-FINAL-ULTIME.md)**.
