# Assets — Kit de marque Cap365

Ce dossier contient les **fondations de design** (tokens) et le **kit graphique**. Les images finales sont rangées dans `../SVG/` et `../PNG/`.

## Contenu
| Fichier | Rôle |
|---|---|
| `colors.css` / `colors.json` | La palette (couleurs de marque, stats, états). Orange `#F5A623` réservé à l'action. |
| `gradients.css` | Les dégradés de marque. |
| `components.css` | Styles de composants (boutons, cartes, jauges). |
| `kit-graphique.md` | La charte : logo, typographies, usages, do/don't. |

## Où sont les visuels ?
- **Vectoriels (`../SVG/`)** : `logo/` (logo, app‑icon, favicon), `icones/` (8 stats + cairn, série, XP…), `badges/` (Commun → Légendaire), `composants/` (carte défi, jauge, radar, progress XP, bouton).
- **Exports PNG (`../PNG/`)** : `ecrans/` (16 maquettes), `fonds/` (arrière‑plans), `composants-rasterises/` (SVG en PNG), `pdf/` (aperçus du livre), et la planche de contrôle.

> Les couleurs et composants ici (`Assets/`) sont la **source de vérité** ; les fichiers SVG/PNG en découlent.
